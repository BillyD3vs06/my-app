# TaskProvider 

TaskProvider is an online application with focus on creating and organizing tasks in administrative purposes. You can either log in as an admin or user. Tasks will be visible for both users and admins, but admins will have significant control of the tasks such as adding, removing and editing tasks. Users may only see the tasks that are directed towards them by the tasks administrators, while the admins sees all tasks they have directed to a user. 

## Cloning TaskProvider

1. Open Gitbash on your computer and type in: git clone https://github.com/BillyD3vs06/my-app.git (this downloads the project to your local computer)
2. Navigate to the project in your terminal by maping out the route, type: cd my-app.
3. The project is divided into two parts: frontend and backend. To start one of them navigate to that specific folder (frontend or backend) and follow the installations instructions there.
